## Project
StickerBridge: an open-source sticker keyboard (Android first, iOS later, desktop hotkey helper much later) that lets users use their own WhatsApp stickers inside Instagram (DM and Stories), synced automatically.

## Current phase
Paused after Android v0.1 (A1). See docs/ROADMAP.md for the next package.

## Hard rules
1. Never commit personal data: real WhatsApp stickers, screenshots, device logs, session files, keystores, local.properties, .env. Test assets must be synthetic and generated by a committed script.
2. No root, jailbreak, modified WhatsApp/Instagram, or reading WhatsApp's private database.
3. Never collect passwords. No central server. Everything on-device.
4. The keyboard must never log or transmit typed text.
5. Unofficial methods (linked-device sync) live in separate, opt-in modules marked EXPERIMENTAL.
6. Do not claim something was tested on a device unless the user reported the result.
7. Minimal dependencies; propose new dependencies before adding them.
8. Do not commit or push unless asked. Work on the branch the task names.
