# Security Policy

StickerBridge is a keyboard. Keyboards can see what users type, so security and privacy are core requirements.

## Our guarantees
- The keyboard never logs, stores or transmits typed text.
- No network access unless a feature explicitly requires it and it is documented.
- No passwords are ever requested.
- User stickers stay on the device.

## Reporting a vulnerability
Please **do not open a public issue** for security problems.
Use GitHub's private reporting: **Security → Report a vulnerability** on this repository.
We aim to respond within 7 days.

## Supported versions
The project is pre-alpha; only the `main` branch is supported.
